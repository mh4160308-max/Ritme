ریتم — نسخه ارتقایافته
======================

قابلیت‌های اضافه‌شده:
- آمار جداگانه روزانه، هفتگی و ماهانه
- زمان برنامه‌ریزی‌شده و مدت فعالیت‌هایی که تیک انجام دارند
- تفکیک آمار بر اساس مطالعه، مهارت‌آموزی، باشگاه، استراحت، اجتماعی و شخصی
- میانگین درصد تکمیل روزانه در بازه انتخابی
- خروجی پشتیبان JSON و بازیابی آن
- خروجی CSV برای بازکردن در Excel
- تأیید پیش از پاک‌کردن تیک‌های روز

ساخت EXE در ویندوز:
1. Node.js نسخه LTS را از https://nodejs.org نصب کنید.
2. مطمئن شوید اینترنت وصل است.
3. روی «ساخت-اپ-ویندوز.bat» دوبار کلیک کنید.
4. بعد از اتمام، فایل‌های نصب‌شونده و portable در پوشه dist خواهند بود.

ساخت EXE در GitHub بدون نصب ابزار ساخت:
1. محتویات این پوشه را در یک مخزن GitHub آپلود کنید.
2. به بخش Actions بروید و workflow با نام «Build Windows EXE» را اجرا کنید.
3. فایل Ritme-Windows-EXE را از Artifacts دانلود کنید.

نکته درباره آمار:
مدت فعالیت‌های انجام‌شده از زمان شروع و پایان برنامه محاسبه می‌شود؛ این نسخه هنوز تایمر واقعیِ مدت مطالعه یا باشگاه ندارد. اطلاعات داخل localStorage مرورگر/اپ نگه‌داری می‌شوند. برای جلوگیری از ازدست‌رفتن داده‌ها، مرتب نسخه پشتیبان بگیرید.
